# Security considerations

This repository is an unmaintained reference and starter-code release, provided
as-is. No versions receive ongoing security support. There is no commitment to
monitor vulnerability reports, respond to disclosures or provide security fixes.
Do not rely on this repository as a vulnerability-reporting or remediation channel.

Before use, review the code and deployment assumptions, assess dependency
vulnerabilities, and keep Requests, urllib3 and your Python runtime updated.
You are responsible for security validation and remediation in your deployment
or fork. Report vulnerabilities in dependencies or the server through the relevant
upstream project's or vendor's published security channels. If you maintain a
public fork, establish your own private reporting channel and support policy.

Do not post credentials, private compound structures, raw instance exports or
proprietary response bodies in public issues or pull requests. Use synthetic
reproductions. Avoid publishing exceptions verbatim: some errors include response
bodies, request URLs or server messages that can reveal deployment information.
